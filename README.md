📊 Profit Analysis

🛠️ Tools & Technologies

- 📗 Excel – Data cleaning and analysis
- 🗄️ MySQL Workbench – Data extraction and SQL queries
- 📈 Power BI – Data visualization and dashboard creation

---

🔄 Project Workflow

1. 🗄️ Extracted data using MySQL Workbench.
2. 🧹 Cleaned and analyzed the data using Excel.
3. 📊 Created visualizations and presented business insights using Power BI.

---

💡 Key Business Insights

- 🚀 R&D Investment: Prioritize Research & Development investment, as it provides the highest return on investment.
- 💰 Administrative Expenses: Reduce administrative overhead, as it shows a weak correlation with net profit.
- 🌎 Geographic Expansion: Focus expansion efforts in New York due to higher average profit margins.

---

🎯 Project Objective

To analyze business profitability, identify key factors influencing net profit, and provide data-driven insights to support strategic business decisions.
